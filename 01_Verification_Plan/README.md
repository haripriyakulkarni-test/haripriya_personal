# Stage ① — Verification Plan (Maker)

Drafting a Verification Plan before it is ready to open a PR for Checker review.

- **Guardrails/** — non-negotiable checks a VP must pass before it's sent for review.
- **Skillset/** — the drafting workflow and self-review checklist for producing a VP.
- **Drafts/** — VP documents drafted at this stage, one per product/release.
